# VSCode Shortcuts

Visual Studio Code offers extensive keyboard shortcuts to enhance productivity, with key bindings differing slightly between Windows/Linux and macOS. For macOS replace **Ctrl** with **Cmd** and **Alt** with **Option**.

## Essential Editing and Navigation

- Command Palette: Access all commands via **Ctrl+Shift+P**.
- Quick Open: Quickly find and open files using **Ctrl+P**.
- Go to Line: Navigate to a specific line number with **Ctrl+G**.
- Go to Symbol: Jump to functions or classes in the current file using **Ctrl+Shift+O**.
- Search: Find text in the current file with **Ctrl+F** and across the entire project with **Ctrl+Shift+F**.

## Code Manipulation

- Comment Lines: Toggle line comments using **Ctrl+/**. For block comments, use **Shift+Alt+A**.
- Select All Occurrences: Highlight text and press **Ctrl+Shift+L** to edit all instances simultaneously.
- Move or Duplicate Lines: Move lines up/down with **Alt+Up/Down**; duplicate them with **Shift+Alt+Up/Down**.
- Delete Line: Remove the current line instantly using **Ctrl+Shift+K**.
- Multi-Cursor: Add a cursor at the next match with **Ctrl+D** or insert cursors by holding **Alt** and clicking.

## Interface and Debugging

- Toggle Sidebar: Show or hide the file explorer with **Ctrl+B**.
- Integrated Terminal: Open or toggle the terminal panel using **Ctrl+`** (backtick).
- Format Document: Automatically format code with **Shift+Alt+F**.
- Start Debugging: Begin a debugging session with **F5**; step over code with **F10** and step into with **F11**.
