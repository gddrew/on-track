# VSCode Shortcuts

Visual Studio Code offers extensive keyboard shortcuts to enhance productivity, with key bindings differing slightly between Windows/Linux and macOS.

## Essential Editing and Navigation

- Command Palette: Access all commands via **Ctrl+Shift+P** (Windows/Linux) or **Cmd+Shift+P** (macOS).
- Quick Open: Quickly find and open files using **Ctrl+P** or **Cmd+P**.
- Go to Line: Navigate to a specific line number with **Ctrl+G**.
- Go to Symbol: Jump to functions or classes in the current file using **Ctrl+Shift+O** or **Cmd+Shift+O**.
- Search: Find text in the current file with **Ctrl+F** (or **Cmd+F**) and across the entire project with **Ctrl+Shift+F** (or **Cmd+Shift+F**).

## Code Manipulation

- Comment Lines: Toggle line comments using **Ctrl+/** (or **Cmd+/**). For block comments, use **Shift+Alt+A** (Windows/Linux) or **Shift+Option+A** (macOS).
- Select All Occurrences: Highlight text and press **Ctrl+Shift+L** (or **Cmd+Shift+L**) to edit all instances simultaneously.
- Move or Duplicate Lines: Move lines up/down with **Alt+Up/Down** (or **Option+Up/Down**); duplicate them with **Shift+Alt+Up/Down** (or **Shift+Option+Up/Down**).
- Delete Line: Remove the current line instantly using **Ctrl+Shift+K** (or **Cmd+Shift+K**).
- Multi-Cursor: Add a cursor at the next match with **Ctrl+D** (or **Cmd+D**) or insert cursors by holding **Alt** (or **Option**) and clicking.

## Interface and Debugging

- Toggle Sidebar: Show or hide the file explorer with **Ctrl+B** (or **Cmd+B**).
- Integrated Terminal: Open or toggle the terminal panel using Ctrl+** (backtick) or **Cmd+.
- Format Document: Automatically format code with **Shift+Alt+F**(Windows/Linux) or **Shift+Option+F** (macOS).
- Start Debugging: Begin a debugging session with **F5**; step over code with **F10** and step into with **F11**.
